# סמן – מערכת אתרים לעסקים (Angular)

## דרישות והפעלה מקומית
- Node.js 20.19 ומעלה (מומלץ Node 22 LTS)
- npm

```bash
npm install
npm start
```
פתחי: http://localhost:4200

## מה כלול
- אתר שיווקי בעברית, RTL ורספונסיבי, עם מראה חם בגווני אדום/אפרסק בהשראת אתר סמן הקיים.
- סמל מיקום אדום עם הילה וטבעות זוהרות, כולל favicon.
- ממשק ניהול ליצירה, עריכה, פרסום, הסרה ושיתוף של עמודי עסקים.
- עמוד עסק עם טלפון, מייל, אתר, כתובת, שעות פעילות, ניווט ושיתוף ב-WhatsApp/SMS/Email.
- העלאת גלריית תמונות מוצרים/מקום בלבד (לא תמונות אנשים) לאחסון Supabase.
- שכבת גישה ל-Supabase Database + Storage וכניסת מנהלת.
- Edge Function לשליחת פניות מייל דרך Resend.
- Meta title/description לעמודי עסקים, sitemap דינמי ו-robots.txt ראשוני.

## חיבור לענן
קראי את `SETUP-CLOUD.md` ובצעי את שלבי ההקמה. פרטי Supabase עדיין placeholders בקובצי environment עד שתיצרי פרויקט משלך. אין אפשרות להפעיל ענן אמיתי בלי פרטי החשבון וההרשאות שלך.

## מבנה
- `src/app/pages/home` – אתר סמן
- `src/app/pages/admin` – ממשק ניהול
- `src/app/pages/business` – תבנית עמוד עסק
- `src/app/services/business.service.ts` – גישה לענן או מצב הדגמה מקומי
- `src/app/services/auth.service.ts` – התחברות מנהלת
- `supabase/migrations` – טבלאות, הרשאות ואחסון
- `supabase/functions/send-contact` – שליחת מייל דרך Resend
- `supabase/functions/sitemap` – מפת אתר דינמית לעמודי עסקים מפורסמים

## חשוב לפני השקה
יש להגדיר Supabase, משתמשת מנהלת, Resend, דומיין ואחסון אתר. יש לבצע בדיקות הרשאות, גיבויים, פרטיות, הגבלת קצב לטופס והגדרות SEO/Google Search Console לפני קבלת לקוחות אמיתיים.

## תיקונים לגרסת נובמבר 2026
- קישורי עמודי לקוחות נפתחים ככתובות מלאות.
- כתובת עמוד נוצרת אוטומטית גם אם הוזן שם עסק בעברית; מתבצעת בדיקת כפילות.
- עיצוב עמוד לקוח צבעוני יותר ומותאם לנייד.
- נוספו כללי overflow כדי למנוע גלילה אופקית של כל האתר.
- נוספו קובצי rewrite ל-Vercel ול-Netlify כדי שקישורים ישירים כמו `/biz/my-business` ייטענו כראוי לאחר פרסום.


## עדכוני נובמבר 2026 – בקרה ודיווח
- לכל עסק יש כפתור הפעלה/השבתה בניהול; עסק לא פעיל אינו נשלף בעמוד הציבורי.
- לכל עסק ניתן להגדיר הצגה בדף הבית, הצגת המלצות והפעלת דוח יומי.
- WhatsApp מוצג רק כאשר הוזן מספר WhatsApp ייעודי; בהיעדרו מוצגת הודעה עם הפניה לטלפון/מייל.
- בעת ניווט מעמוד עסק חזרה לאתר סמן, ה-favicon הראשי מוחזר.
- נוספו רישום כניסות לעמודי עסקים ותשתית לדוח יומי למנהלת ולבעלי עסקים. יש להשלים SQL, פריסת Edge Functions וסודות לפי SETUP-CLOUD.md.


## עדכון נובמבר 2026 (ב) – עריכת תוכן אתר סמן
- במסך `/admin` נוספו שתי לשוניות: **ניהול עסקים** ו**עריכת תוכן אתר סמן**.
- ב"עריכת תוכן אתר סמן" אפשר לערוך את כל הטקסטים בעברית של דף הבית, להסתיר אזורים בלי למחוק אותם, לשחזר את הטקסט המקורי ולחזור לגרסה הקודמת. התוכן נשמר ב-Supabase (`seman_site_content`) ולכן לא נמחק בפריסת גרסה חדשה.
- הטקסטים המקוריים נשארים בקוד ב-`src/app/models/site-content.model.ts` (`DEFAULT_CONTENT`), ושם גם מוגדר מה ניתן לערוך בכל אזור (`SECTION_DEFS`). להוספת שדה ניתן לערוך מקום אחד ולהוסיף אותו גם לתבנית ב-`home.component.ts`.
- פירוט התיקונים שנעשו בסקירה: `REVIEW-REPORT-HE.md`.
